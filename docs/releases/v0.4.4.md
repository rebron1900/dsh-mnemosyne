# v0.4.4

## Fixes

- Auto-sleep threshold: a cleared `sleep_threshold` now falls back to the upstream default (50) instead of firing every periodic check.
- Session-disposed consolidation: sessions that never auto-stored a memory no longer trigger a forced sleep.
- Scope migrations (`default` → `global`, scoped → `default`) run under the same per-bank memory lock as the tools.
- Diagnose stays healthy when the auxiliary consolidation count is unavailable.
- Settings panel: merged a duplicated `disabled` prop on the model picker button.

## Other

- Added an automated awesome-dsh-plugin storefront sync (fork-based PR).
- Documentation synced (README, design, data-flow comparison). 117 tests: 96 unit + 17 integration + 4 client.
