# v0.4.3

## Highlights

- Added optional per-session memory isolation with `sessionScope`, including root-session sharing for subagents.
- Added migration routes and Settings actions for moving legacy `default` memories to `global` and session-scoped memories back to `default`.
- Added session-aware store, recall, delete, and sleep support through the Mnemosyne CLI environment.
- Restricted automatic memory sync to genuine user messages and excluded injected plugin, workspace-instruction, and skill-catalog context.
- Added `syncRoles` configuration support and bridged Mnemosyne write-filter settings from `config.yaml` into CLI calls.
- Hardened configuration handling with an allow-list and masked secret values in the Settings API.
- Added the project banner and refreshed English and Simplified Chinese documentation.

## Validation

- `pnpm test`
- 99 tests: 81 unit, 15 integration, and 3 client tests
