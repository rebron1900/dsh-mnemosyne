# v0.5.0

> Release date: 2026-08-26

## Highlights

- Added a read-only Mnemosyne memory dashboard that can be opened from the existing Settings panel when `dsh-better-sidebar` is available.
- Vendored the dashboard web assets into the plugin package so the view is served by the existing DSH listener without a second process, port, login flow, or remote asset dependency.
- Added active-bank dashboard routes for overview counts, recent/searchable memories, today's activity, knowledge triples, consolidation history, memory details, graph data, lifecycle summaries, and compatible upstream dashboard views.
- Added schema-tolerant SQLite reads for current and legacy Mnemosyne tables, including duplicate-memory suppression and bounded pagination, filtering, sorting, and response fields.
- Kept the dashboard read-only: browser requests are GET-only, local/same-origin checks are enforced, database access uses SQLite read-only mode, and no arbitrary database path or SQL is accepted from the browser.
- Added optional and lazy Better Sidebar registration so the existing Mnemosyne Settings panel continues to work when the sidebar plugin is not installed or loads later.
- Added English and Simplified Chinese dashboard labels, a dedicated brain icon, active-language switching, and a single-instance dashboard tab.

## Compatibility

- `dsh-better-sidebar@^0.16.1` is an optional peer dependency. Dashboard integration is unavailable when it is absent; the core plugin and Settings panel remain available.
- The dashboard reads the active Mnemosyne bank resolved by the plugin. It does not aggregate other banks or alter session-scope behavior.
- Dashboard assets and their upstream notices/license are included under `assets/dashboard/`.

## Validation

- `pnpm test`
- 124 tests passed: 103 unit, 17 integration, and 4 client tests.
- Dashboard route tests cover parameter bounds, active-bank reads, schema-tolerant responses, GET-only enforcement, same-origin rejection, read-only API behavior, static asset containment, and optional Better Sidebar registration.

## Version Iteration

- `v0.4.4` focused on auto-sleep correctness, session-disposed consolidation, scope migration locking, diagnostics resilience, storefront sync, and documentation.
- `v0.5.0` adds the first user-facing memory inspection surface: a bundled, local, read-only dashboard while preserving the existing CLI-first tools, automatic memory behavior, configuration flow, and data isolation.
